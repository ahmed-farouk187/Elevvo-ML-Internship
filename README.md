# Elevvo Machine Learning Internship

My solutions to the Elevvo machine learning internship tasks. Each task folder has a Jupyter notebook, a README with the results, and the data used.

| Task | Topic | Main result |
|---|---|---|
| [Task 1 - Student Score Prediction](Elevvoo/Task%201) | Linear regression | R2 0.25 with hours studied, 0.68 with more features |
| [Task 2 - Customer Segmentation](Elevvoo/Task%202) | K-Means clustering | 5 customer groups (silhouette 0.555) |
| [Task 3 - Forest Cover Type Classification](Elevvoo/Task%203) | Random Forest vs XGBoost | XGBoost accuracy 96.6% |
| [Task 4 - Loan Approval Prediction](Elevvoo/Task%204) | Logistic Regression vs Decision Tree | Decision Tree F1 0.961 for rejected loans |
| [Task 5 - Movie Recommendation System](Elevvoo/Task%205) | Collaborative filtering, SVD | Precision@10 0.197 |
| [Task 6 - Music Genre Classification](Elevvoo/Task%206) | SVM, Random Forest, KNN | SVM accuracy 76.5% |
| [Task 7 - Sales Forecasting](Elevvoo/Task%207) | Time series regression | Random Forest MAPE 4.34% |
| [Task 9 - Predictive Maintenance](Elevvoo/Task%209) | Random Forest vs XGBoost, threshold tuning | 1 false alarm (FDR 0.019) |

All notebooks were made in Google Colab with Python, pandas, numpy, matplotlib, scikit-learn and xgboost.
